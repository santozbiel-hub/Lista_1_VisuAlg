# Lista 2

[Enunciado em PDF](enunciado.pdf), [soluções reunidas em PDF](lista-2-solucoes-visualg.pdf) e 12 soluções em VisuAlg (`exercicio01.alg` a `exercicio12.alg`).

O PDF do enunciado solicita fluxogramas em PNG para a entrega acadêmica. Os arquivos `.alg` e o PDF das soluções são implementações textuais dos problemas; não substituem os PNGs exigidos pela disciplina.

Abra cada arquivo `.alg` no VisuAlg para executar. A execução direta no VisuAlg ainda não foi verificada neste ambiente.
