# Lista 2

[Enunciado em PDF](enunciado.pdf) e 12 soluções em VisuAlg (`exercicio01.alg` a `exercicio12.alg`).

O PDF solicita fluxogramas em PNG para a entrega acadêmica. Estes arquivos `.alg` são uma implementação textual dos mesmos problemas, conforme pedido para este repositório; não substituem os PNGs exigidos pela disciplina.

Abra cada arquivo `.alg` no VisuAlg para executar. A execução direta no VisuAlg ainda não foi verificada neste ambiente.
